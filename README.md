Ridge, Bootstrap y Validación de Modelos

Objetivo: Aplicar regresión Ridge, métodos de remuestreo 

(Bootstrap/Jackknife) y técnicas de validación cruzada para construir y evaluar modelos predictivos robustos.

Contexto: Predecir el promedio final de estudiantes universitarios usando información académica previa, socioeconómica y de dedicación.
